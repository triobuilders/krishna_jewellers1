Shree Krishna Jewellers — Combined App Package

Included: index.html (latest GST + Advance Order demo), PWA manifest, service worker, app icons, and setup notes.

GitHub: Extract this ZIP and upload the files to the repository root. Do not upload customer records or backup JSON files. Enable GitHub Pages over HTTPS, then use that URL in PWABuilder if you want an Android package.

Privacy: The app is intended to keep records in this device/browser storage and does not include cloud sync. However, this demo package has not been fully security-audited or fully tested for persistent customer records. Test saving, backup, and restore before entering real customer data. Browser storage may be lost if app data is cleared or the app is uninstalled. Export backups and store them securely on your own device.

PWA: manifest and service worker are included. A standalone display setting usually hides the browser URL bar when installed correctly, but verify the generated APK on your device. This ZIP is not an APK.
